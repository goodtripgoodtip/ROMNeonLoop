# NeonLoop

Use [the build instructions](GitSource/BUILD.md) for the supported Steam build. Keep the Steam installation read-only. Build into a separate output folder and keep generated game copies, soundtrack packs, cutscenes, caches, and logs out of the source repository.

Preserve the credit for [Good Trip Good Tip](https://github.com/goodtripgoodtip) and [OpenAI Codex](https://github.com/openai/codex). Review redistribution terms before attaching release ZIPs or adding game screenshots to the repository. Keep dependency notices with the source.
