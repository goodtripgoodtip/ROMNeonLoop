# NeonLoop

A free Windows mod for **2064: Read Only Memories** on Steam. Change the look, make the text easier to read, and choose a different soundtrack while you play.

NeonLoop is an unofficial fan mod built with custom mod code. The downloads contain zero original game assets or code. Setup requires your Steam copy of 2064: Read Only Memories and applies the mod locally.

**[Download NeonLoop Setup](https://github.com/goodtripgoodtip/ROMNeonLoop/releases/download/v0.6.9/NeonLoop-Setup.exe)** · [Optional music packs](https://github.com/goodtripgoodtip/ROMNeonLoop/releases/tag/v0.6.9)

![NeonLoop presents the apartment with vivid magenta lighting.](Screenshots/Showcase-NeonLoop.png)

## Start playing

1. Install **2064: Read Only Memories** on Steam and close the game.
2. Open **NeonLoop-Setup.exe** and follow the wizard. Select **Play Now** when it finishes.
3. Press **F10** in the game to open the NeonLoop menu. Press it again to return to the game.

<summary>Music packs and setup help</summary>

Easy Install preselects Dark Synthwave. Clear that selection to keep the original music. To add a downloaded music pack later, leave it zipped and choose **Get music packs → Add a downloaded pack** in the launcher.

- [Dark Synthwave](https://github.com/goodtripgoodtip/ROMNeonLoop/releases/download/v0.6.9/neonloop_dark_synthwave.zip) · Karl Casey @ [White Bat Audio](https://whitebataudio.com/)
- [Cinematic Sci-Fi](https://github.com/goodtripgoodtip/ROMNeonLoop/releases/download/v0.6.9/neonloop_cinematic_sci_fi.zip) · [Scott Buckley](https://www.scottbuckley.com.au/library/)
- [Noir Jazz](https://github.com/goodtripgoodtip/ROMNeonLoop/releases/download/v0.6.9/neonloop_noir_jazz.zip) · Kevin MacLeod, [Incompetech music catalog](https://www.incompetech.com/music/royalty-free/music.html)

Select a soundtrack in **F10 → Music**. Setup can also remix cutscenes using your Steam copy. That takes longer and can resume if interrupted.

- If setup can’t find the game, use **Manage → Browse local files** in Steam to find the folder, then choose it in NeonLoop’s **Find game** screen.
- **Manage downloads and tools** in Setup options shows which setup files you can remove to free space. For new installs, those files and the private game copy are in the **Data** folder inside NeonLoop.
- Run **Uninstall NeonLoop** from the install folder or use **Setup options** in the launcher. Your Steam copy and saves stay in place.
- Windows may flag the unsigned installer as unfamiliar. Use the official release link. [SHA-256 checksums](https://github.com/goodtripgoodtip/ROMNeonLoop/releases/download/v0.6.9/SHA256SUMS.txt)
